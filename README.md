\# Legacy Loan Calculator (2009)



A simple legacy-style C++ loan/EMI calculator for the console.



It calculates:



\- Monthly payments (EMI)

\- Total interest

\- Loan balance

\- Effective interest rate (including fees)



---

\### Using g++

```bash

g++ -std=c++11 LoanCalculator.cpp LoanCalculatorMain.cpp -o calc
